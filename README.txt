簡記 v3.3 更新包

本次整合：
1. 保留雲端同步與原 Supabase 專案設定。
2. 設定頁新增／保留「變更共用密碼」功能，使用登入中的 Supabase session 更新密碼。
3. 手機版新增按鈕改為圓形「＋」，並提高位置；桌面版維持既有位置與樣式。
4. 更新 Service Worker 快取版本，協助 GitHub Pages 載入新版。

更新方式：
1. 先下載並解壓縮本 ZIP。
2. 將 index.html 與 sw.js 兩個檔案上傳至 GitHub 專案根目錄，選擇覆蓋同名檔案。
3. 不要刪除或重建 Supabase 使用者、資料表或 app_data 資料。
4. GitHub Pages 部署完成後，在手機重新整理網站；若仍看到舊版，可關閉網站後重新開啟，或清除該網站快取。

密碼變更注意：請先在簡記登入成功，再到「設定」→「變更共用密碼」。密碼至少 8 個字元。變更後，其他裝置請使用新密碼重新登入。此功能依賴目前裝置仍有有效登入 session。
